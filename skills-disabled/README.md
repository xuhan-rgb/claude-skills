# 已关闭技能暂存

这里保存本机 Codex 配置中已关闭的技能，安装脚本不会扫描本目录。
同名技能有多份配置时，只要有一份启用，就保留在 `skills/`。

要恢复某个技能：将对应目录移回 `skills/`，需要在 Codex 启用时再加入 `config/codex/enabled-skills.json`，然后运行 `bash install.sh`。
本次只整理仓库，未移动本机正在使用的技能目录；安装器也不会清理以前已安装的技能。
